### 🧭 How I work

I treat **product and engineering as one discipline**. Specs that don't survive contact with code aren't specs — they're guesses. So I ship.

- **Lean validation first.** Cheapest possible version of the idea, in front of real users, this week.
- **Vertical slices over horizontal layers.** A working end-to-end flow beats a polished half.
- **Boring stack, sharp judgment.** Next.js + Postgres + Vercel covers 95% of what early products need.
- **Distribution is product.** A feature nobody finds doesn't exist.
